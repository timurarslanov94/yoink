FAQ

What does Yoink do?

Hover over any element on any website, click to lock it, and copy a complete bundle to your clipboard — HTML, CSS, Tailwind classes, JSX, fonts, asset URLs, screenshots — ready to paste into Claude or ChatGPT for pixel-perfect reproduction.

Is Yoink really free?

Yes. 100% free, forever. No paywall, no premium tier, no ads, no accounts.

How is it different from CSS Peeper, CSS Scan or VisBug?

Yoink is built for AI workflows. Every copy operation produces an AI-ready bundle with a prompt header that instructs Claude or ChatGPT to reproduce the element exactly. It also has recursive Deep CSS for nested elements, full-page screenshot stitching, Tailwind conversion, JSX export, accessibility audit, and 10-language UI — all free.

Does it work on React / Vue / Next.js / Webflow / Framer?

Yes. Yoink works on any standard webpage including React, Vue, Next.js, Webflow, Framer, WordPress, and static sites. It cleans framework noise (data-reactid, ng-*, etc.) automatically.

Does Yoink collect any data?

No. Yoink does not transmit, store, or sell any data. There are no servers, no analytics, no accounts. Everything happens locally in your browser.

Can I use Yoink commercially?

Yes, free for personal and commercial use. You may not modify, redistribute, or publish derivatives on extension marketplaces — see the license.
